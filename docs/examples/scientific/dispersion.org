* Assumptions
For a uniform, lossless waveguide, take the propagation constant $\beta$ to be
independent of position. The phase grows linearly with distance.

* Derivation
Starting from $\partial E / \partial z = i\beta E$, integration gives
\[
E(z) = E(0)\exp(i\beta z), \qquad \phi(z) = \beta z.
\]
This simplified model connects to [[id:4e416ea0-dcf1-4bb6-bc8e-5d953292119a][Waveguide propagation]].

* Numerical illustration

standard library. Select a project interpreter via an Org Babel =:python= header.
